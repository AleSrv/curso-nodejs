# Curso Interactivo de Node.js - 12 Semanas

¡Bienvenido/a!

Este es un curso práctico de Node.js diseñado para que aprendas haciendo. Cada semana se enfoca en un nuevo conjunto de conceptos, culminando en un proyecto para aplicar lo aprendido.

## ¿Cómo funciona?

1.  **Estructura Semanal:** El curso está dividido en 12 carpetas, una por cada semana (`semana-01`, `semana-02`, etc.).
2.  **Contenido de la Semana:** Dentro de cada carpeta semanal, encontrarás:
    *   `README.md`: Un archivo con la teoría, los objetivos y la descripción de los ejercicios y el proyecto de la semana. ¡Léelo primero!
    *   `teoria/`: Contiene ejemplos de código que ilustran los conceptos teóricos.
    *   `ejercicios/`: Aquí es donde debes resolver los ejercicios propuestos. Hay una carpeta para cada uno.
    *   `proyecto/`: El espacio para desarrollar el proyecto de la semana. Ya tiene un `package.json` para que puedas empezar a instalar dependencias.
3.  **Tu Progreso:** La idea es que escribas tu propio código en las carpetas `ejercicios` y `proyecto`. Como los archivos están en tu máquina local, tu progreso se guarda automáticamente. Puedes usar `git` para llevar un control de versiones de tus soluciones.

## Empezar

Simplemente navega a la carpeta `semana-01`, abre el archivo `README.md` y ¡comienza tu viaje con Node.js!

¡Mucho éxito!
